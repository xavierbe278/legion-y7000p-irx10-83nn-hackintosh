# 配置样本目录

这里放 **去敏后** 的 `config.plist` 片段，供对照。

由于 `config.plist` 含序列号 / MLB / SystemUUID 等机型敏感信息，本仓库默认**不放完整配置**。

需要时请从自己的备份里取：

```text
backup/final-config.plist      # 当前可用（含 dk=0x0）
backup/golden-config.plist     # 无触控板稳定版
```

对照要点见主 [README](../README.md) 的「关键配置」章节。
